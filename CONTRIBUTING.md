# Contributing

Thank you for your interest. reqochet is maintained by a small team; changes are welcome.

- **A bug or an idea:** open an issue. For a bug, say the version (Settings → Environment), what you did, what you
  expected and what happened; attach a small made-up project if you can (never real requirements).
- **A security problem:** please do not open an issue — see `SECURITY.md`.
- **A change:** read `docs/ONBOARDING.md` (the module map and one change end to end) and `docs/DEVELOPING.md` (setup).
  `npm run check` must be green; add a test for what you change; every word on screen goes into the language files
  (`src/shared/text*.ts`), every colour into `config/theme.json`. Then open a pull request with a short description.
- **Licence:** by contributing you agree that your change is shared under the project's licence (`LICENSE.md`,
  PolyForm Shield 1.0.0).
