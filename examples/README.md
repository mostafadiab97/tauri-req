# Examples

## smart-home-climate — a fictional project to explore reqochet

About 1,200 invented requirements for a "Smart Home Climate System": stakeholder needs, system, software, hardware
and interface requirements, design elements, use cases, test cases, risks, defects and change requests, linked to
each other. It is made to show every kind of content reqochet handles:

- every item type, field and link type; a deep hierarchy (ten levels) and a wide one (650 children, "Show more");
- long Markdown texts, tables, code, non-English text and special characters;
- a few **deliberately broken files** (an unreadable header, a file renamed by hand…) under "Deliberately broken test
  data": reqochet lists them as problems in the status bar instead of failing.

Everything in it is invented; no real product, company or person.

### Try it

1. Copy the folder `smart-home-climate` somewhere outside this repository (for example to your Documents folder).
2. To see history, Compare and baselines, make it a Git repository first:

   ```
   cd smart-home-climate
   git init
   git add .
   git commit -m "Example project"
   ```

   (Without Git it opens too; reqochet then says that history and sharing need Git.)
3. In reqochet: **Open repository…** and choose the `smart-home-climate` folder.

### How it was made

Generated by `npm run gen:scenario -- <folder> 1200` (`tools/generate-scenario-repo.mts`, deterministic: the same
command makes the same files), with the document folder named "Smart Home Climate". The automatic acceptance run on
GitHub uses a copy of it to test the installed app (`.github/workflows/`).
